Flask API Setup
==============

1. Install dependencies (already done):
   - Flask

2. Main entry point: `backend/app.py`
   - Example endpoint: `/api/health`

3. To run the API:
   C:/my-saas-app/.venv/Scripts/python.exe app.py

4. Add more routes in `app.py` or organize into blueprints for larger apps.

5. Access the API at: http://localhost:3000/api/health
